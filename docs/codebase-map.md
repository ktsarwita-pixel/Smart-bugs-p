## Entry points


`src/main.ts` boots the app: it creates the `Game`, wires the renderer
and the HUD, and owns the animation loop. Everything else is called from
`Game.update()`.

## Conventions

- One module per concept; the folder name is the namespace (`src/world/`,
  `src/entities/`, `src/game/`, `src/ui/`, `src/render/`, `src/core/`).
- Content is data: blocks, items, recipes, upgrades and contracts live in
  registries and are consumed by `Game`.
- `Game` is the orchestrator; entities own their own state and physics.
- The renderer never mutates game state; the game never touches Three.js
  objects except through `src/render/` helpers.
